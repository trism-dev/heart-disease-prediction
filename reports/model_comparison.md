## Selection

**Shipped: Logistic regression.** no tree model beat LR by more than one CV std; ties go to LR. Rule: a tree model ships only if its CV recall
beats logistic regression by more than one CV standard deviation at comparable precision (within
0.05); ties go to LR. The shipped model catches 27 of 28 sick test patients
(recall 0.964, 1 missed) with precision 0.730 and
10 false alarms.

Thresholds are the highest cut-off with out-of-fold train recall ≥ 0.90; the test set was used once,
only to report. Class weighting (`balanced`) inflates predicted probabilities, so the app's
percentage is a risk score, not a calibrated prevalence estimate (see `figures/calibration.png`).

Sanity check: test accuracy 0.820, recall 0.964
(inside the plausible range, no leakage alarm).

Note: XGBoost reaches recall 1.00 on test at threshold 0.029 with specificity 0.485. That comes from flagging many healthy patients, not from leakage (accuracy stays low).
